# Referências visuais

Coloque aqui de 3 a 6 prints de apps ou sites cujo visual você gosta (PNG ou JPG). O Claude Code lê imagens e usa estas referências na Fatia 1 para propor as direções visuais.

Para cada print, adicione uma linha na lista abaixo dizendo o que você gosta nele. Isso vale mais que o print sozinho.

| Arquivo | O que eu gosto |
| --- | --- |
| `exemplo-mapa.png` | (ex.: o mapa ocupa a tela toda e os cards flutuam por cima) |

Dicas:

- Misture tipos: um app de mapa, um app de avaliações, um app de registro pessoal (filmes, treinos, livros).
- Inclua pelo menos um print de algo que você **não** quer, com o motivo.
- Use prints de telas de celular, porque o Lugora é mobile-first.
