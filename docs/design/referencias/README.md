# Referências visuais

Coloque aqui de 3 a 6 prints de apps ou sites cujo visual você gosta (PNG ou JPG). O Claude Code lê imagens e usa estas referências na Fatia 1 para propor as direções visuais.

Para cada print, adicione uma linha na lista abaixo dizendo o que você gosta nele. Isso vale mais que o print sozinho.

Tom pedido: urbano, leve, sem muita informação disputando a atenção.

| Arquivo | O que eu gosto (descrição do próprio arquivo) |
| --- | --- |
| `feed_mostrando_com_imagens_ou_sem_elas_...` | Feed com os lugares recentes dos amigos e os mais visitados das últimas semanas, com ou sem imagem, além dos meus lugares recentes com notas. |
| `home_page_view_stats_do_aplicativo_pelo_computador.jpg` | Página inicial e estatísticas do app no computador. |
| `imagens_odos_lugares_com_comentarios_de_avaliacoes.jpg` | Imagens dos lugares com os comentários das avaliações. |
| `mapa_com_opcao_de_mostrar_as_fotos_dos_lugares_...` | Mapa com a opção de mostrar as fotos dos lugares ao tocar no lugar. |
| `mapa_mostrando_os_lugares_para_vistiar_com_icones_pela_cidade.jpg` | Mapa com os lugares para visitar marcados por ícones pela cidade. |
| `perfil_mostrando_lugares_favoritos_...` | Perfil com lugares favoritos, biografia, foto de perfil e minhas listas (como "Quero ir"). |

Ainda falta um print do que **não** se quer.

Os prints são de outros apps e ficam só na sua máquina: o `.gitignore` deixa de fora tudo desta pasta, menos este README.

Dicas:

- Misture tipos: um app de mapa, um app de avaliações, um app de registro pessoal (filmes, treinos, livros).
- Inclua pelo menos um print de algo que você **não** quer, com o motivo.
- Use prints de telas de celular, porque o Lugora é mobile-first.
