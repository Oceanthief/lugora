# Decisões técnicas (ADRs)

Um ADR (*Architecture Decision Record*) é um arquivo curto que registra uma decisão: o contexto, as opções, o que foi escolhido e as consequências. Serve para não rediscutir o que já foi decidido e para mostrar o raciocínio a quem lê o projeto.

Para criar um novo, use a skill `/adr <título>` no Claude Code, ou copie `0000-modelo.md`.
