# 7.9 Sequência semanal (Fase 2)

- Uma semana conta se houver pelo menos 1 visita com data naquela semana, registrada em até 7 dias depois da visita. Isso impede preencher semanas passadas só para manter a sequência.
- Um “congelamento” por mês (semana de prova, doença, viagem a trabalho).
- Pode ser ocultada; nenhuma notificação de culpa.
- Só entra depois de medida a retenção sem ela (seção 6).
