# 7.15 Convites e viagem em grupo (Fase 2)

- Cada convite tem um código e identifica quem convidou. Isso permite medir o coeficiente viral (K): novos usuários vindos de convite ÷ usuários ativos no período.
- Viagem em grupo: ao registrar uma viagem, a pessoa marca quem foi junto, e quem foi marcado recebe um convite com a viagem já preenchida.
- Listas públicas abrem sem login, com convite para criar o próprio mapa. É o principal mecanismo de indicação.
