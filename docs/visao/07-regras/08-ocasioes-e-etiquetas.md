# 7.8 Ocasiões e etiquetas

| Tipo | Etiquetas iniciais |
| --- | --- |
| Ocasião | Romântico · Com amigos · Em família · Sozinho(a) · Trabalhar/estudar |
| Tema | Geek · Esportes · Cultura · Ar livre · Vida noturna |
| Atributo | Barato · Pet friendly |

- Lista fixa, editável pela administração; até 3 etiquetas por visita.
- **Etiqueta do lugar:** aparece quando pelo menos 30% de quem avaliou marcou, com no mínimo 5 avaliadores (parâmetros).
- Revisar a lista depois da Fase 0, com base no que as pessoas realmente marcam.
